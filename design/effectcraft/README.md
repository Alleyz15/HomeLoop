# Welcome-page motion source

For the downloaded macOS app and command-line tool, see [local setup](LOCAL_SETUP.md).

Original HomeLoop artwork authored through **EffectCraft 0.10.0**. The SVG
shapes in `welcome-journey.jsx` are imported into real editable EffectCraft
layers, then animated with eased scale/position/rotation/opacity keyframes,
native Trim Paths, and a parent camera rig. No AI image service,
stock footage, demo property, or financial figures are used.

- `welcome-journey.jsx`: reproducible artwork and animation source.
- `welcome-journey.ecproj`: editable native project, generated by EffectCraft.
- `../../apps/web/public/animations/homeloop-journey.mp4`: thirteen-second, muted,
  760 × 700 H.264 render at 24 fps.
- `../../apps/web/public/animations/homeloop-journey-poster.png`: still rendered
  by EffectCraft at 9 seconds for reduced motion, blocked autoplay and errors.

From the repository root, with `effectcraft-cli` on PATH:

```powershell
effectcraft-cli script design/effectcraft/welcome-journey.jsx --empty --save-as design/effectcraft/welcome-journey.ecproj
effectcraft-cli render-frame --project design/effectcraft/welcome-journey.ecproj --comp "HomeLoop Journey" --time 9 --out apps/web/public/animations/homeloop-journey-poster.png
effectcraft-cli render --project design/effectcraft/welcome-journey.ecproj --comp "HomeLoop Journey" --out apps/web/public/animations/homeloop-journey.mp4 --format h264 --fps 24 --start 0 --end 13 --audio off
```

The first nine seconds unfold the landscape, assemble both houses in stages,
draw the connection with a travelling marker, warm the windows, and push toward
the new home. Seconds 9–13 match at the ends: only trees and window warmth move.
The webpage automatically plays the entrance once, then repeats this ending
segment without manual playback controls. Reduced motion uses only the still
and cancels page reveals and hover
movement, including when the setting changes while the page is open.

The webpage does not request the video when reduced motion is initially enabled.
The asset URLs use a `v=2` query to invalidate the earlier six-second media in
browser/Next Image caches; bump it when replacing the animation in a later version.
Pointer depth, one-time scroll reveals and hover reactions are implemented in
the web components/CSS, not baked into the film. Page text and navigation are
HTML, separate from the decorative video. The source artwork may be reused
and edited within HomeLoop.

Browser acceptance checks (with the web app running and Playwright available):

```powershell
node scripts/check_welcome.mjs
```

The checks sample distinct video frames; verify automatic playback and ending-loop;
verify pointer depth, scroll/hover triggers, responsive overflow, navigation,
runtime reduced-motion changes and video-error fallback.

The script uses installed Microsoft Edge in headless mode. If Playwright is
installed outside the repository, set `WELCOME_PLAYWRIGHT_MODULE` to its
absolute `index.mjs` path. `WELCOME_ARTIFACT_DIR` selects the screenshot folder;
the default output is gitignored under `apps/web/.next/welcome-qa`.
